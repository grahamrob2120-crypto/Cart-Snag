# Cart Snag production web foundation

This isolated Next.js App Router + TypeScript + Tailwind project is **not** a completed customer application. The existing GitHub Pages frontend remains on the root of the repository. Do not publish this replacement until payment, database authorization, verified pricing, and mobile acceptance gates pass.

Run `npm install`, `npm test`, `npm run typecheck`, and `npm run build` from `web/`. No production secrets are required for this foundation. A lockfile and CI installation pinning are required before release.
